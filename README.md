# SARMAT BAVARIA BAR — сайт

Статический адаптивный сайт на HTML, CSS и JavaScript. Не требует сборки и серверной части.

## Запуск локально

Откройте `index.html` в браузере. Для локального сервера можно использовать расширение Live Server в VS Code.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий GitHub.
2. Загрузите в него все файлы и папку `assets` из этого проекта.
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем Save.
6. После публикации GitHub покажет адрес сайта.

## Что уже реализовано

- Адаптивная главная страница, меню, бильярдный раздел, галерея и контакты.
- Фирменная палитра чёрный / изумрудный / золото с акцентами логотипа.
- Логотип и favicon на основе предоставленного изображения.
- Интерактивное меню с категориями и поиском; без фотографий блюд.
- Оригинальное меню открывается в увеличенном просмотре.
- CSS-анимация микрофона и нот.
- Лёгкий бокал, наполняющийся при прокрутке (CSS, без WebGL).
- WhatsApp с готовым текстом и Instagram-ссылкой.
- Лайтбокс галереи, мобильная навигация, reduced-motion.
- WebP-изображения, lazy loading для части галереи, IntersectionObserver и requestAnimationFrame.

## Важно проверить перед публикацией

Меню перенесено с предоставленного фото. В оригинале часть надписей мелкая и местами размытая, поэтому некоторые названия могут требовать ручной сверки. Цены перенесены по читаемым значениям на изображении. Расписание и адрес не указаны, поэтому сайт честно сообщает, что эти данные нужно подтвердить.

Instagram не предоставляет гарантированный публичный способ автоматически выгружать Stories/Reels. В текущем проекте размещены предоставленные фотографии и прямая ссылка на профиль; видео можно добавить отдельными файлами после их получения.

Для обновления меню измените массив `menuData` в `script.js`. Для замены фотографий замените WebP-файлы в `assets`, сохранив имена.
